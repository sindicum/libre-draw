# Live Demo

Try LibreDraw directly in your browser. Use the toolbar buttons on the map to place points, draw lines, draw polygons, and edit existing features.

**Controls:**
- **Draw Point** (pin icon): Click or tap to place a point
- **Draw Line** (line icon): Click to add vertices, double-click to finalize the line
  - Finalizing a line keeps draw-line mode active so you can continue drawing
- **Draw** (polygon icon): Click to add vertices, double-click to close
  - Closing a polygon keeps draw mode active so you can continue drawing
- **Select** (cursor icon): Click a feature to select, drag a point to move it, drag near a line to move it, or drag polygon vertices to edit
- **Split** (scissors icon): Split a polygon into two with a two-point line
- **Setback** (polygon with dashed line icon): Select an edge and offset it inward by distance
- **Delete** (trash icon): Delete the selected feature
- **Undo / Redo**: Undo or redo the last action
